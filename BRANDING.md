# ⚡💫 PayPulse - Brand Identity

## Brand Name
**PayPulse**

## Tagline
*"Send crypto anywhere, anytime"*

## Brand Symbol
**⚡💫** (Lightning Bolt + Sparkles)

### Symbol Meaning
- **⚡ Lightning Bolt**: Represents speed, power, and instant transactions
- **💫 Sparkles**: Represents innovation, magic, and the seamless experience
- **Combined**: The fusion symbolizes the "pulse" of payments - fast, reliable, and always flowing

## Brand Colors

### Primary Palette
- **Solana Green**: `#14F195` - Success, growth, online mode
- **Solana Purple**: `#9945FF` - Premium, trust, blockchain
- **Cyan Accent**: `#00D4FF` - Innovation, Bluetooth, offline mode

### Secondary Palette
- **Dark Background**: `#0A0A0F` - Modern, sleek, professional
- **Card Background**: `#1A1A24` - Depth, layering
- **Secondary Dark**: `#2A2A3A` - Interactive elements

### Status Colors
- **Success**: `#14F195` (Green)
- **Warning**: `#FFA500` (Orange)
- **Error**: `#FF6B9D` (Pink)
- **Info**: `#00D4FF` (Cyan)

## Typography

### Font Families
- **Primary**: System Default (San Francisco on iOS, Roboto on Android)
- **Monospace**: For addresses and transaction IDs
- **Weights**: Regular (400), Semibold (600), Bold (700)

### Font Sizes
- **Hero**: 48px - Large numbers, balances
- **Title**: 32px - Screen titles
- **Heading**: 24px - Section headers
- **Body**: 16px - Main content
- **Caption**: 14px - Secondary text
- **Small**: 12px - Labels, metadata

## Brand Voice

### Personality
- **Innovative**: Cutting-edge technology made accessible
- **Trustworthy**: Secure, reliable, transparent
- **Friendly**: Approachable, helpful, supportive
- **Empowering**: Gives users control and freedom

### Tone
- Clear and concise
- Positive and encouraging
- Professional yet conversational
- Technical when needed, simple by default

### Writing Style
- Use active voice
- Short sentences
- Avoid jargon
- Explain technical terms
- Focus on benefits, not features

## UI Components

### Buttons
- **Primary**: Green background (#14F195), black text
- **Secondary**: Dark background (#2A2A3A), green text
- **Destructive**: Pink background (#FF6B9D), white text
- **Border Radius**: 12px
- **Padding**: 16-18px vertical

### Cards
- **Background**: #1A1A24
- **Border Radius**: 16px
- **Padding**: 20-24px
- **Shadow**: Subtle, optional

### Icons
- **Style**: Emoji-based for consistency across platforms
- **Size**: 24-48px depending on context
- **Spacing**: 8-12px from text

### Status Badges
- **Border Radius**: 20px (pill shape)
- **Padding**: 6px horizontal, 4px vertical
- **Font Size**: 12px
- **Font Weight**: 600 (semibold)

## Animation Guidelines

### Transitions
- **Duration**: 200-300ms
- **Easing**: Ease-in-out
- **Type**: Fade, slide, scale

### Loading States
- **Spinner**: Activity indicator
- **Color**: Primary green (#14F195)
- **Size**: 32-48px

### Micro-interactions
- **Button Press**: Scale down to 0.95
- **Toggle**: Smooth slide animation
- **Card Tap**: Subtle scale or opacity change

## Accessibility

### Color Contrast
- Text on dark background: Minimum 4.5:1 ratio
- Interactive elements: Minimum 3:1 ratio
- Status indicators: Don't rely on color alone

### Touch Targets
- Minimum size: 44x44px (iOS), 48x48px (Android)
- Spacing between targets: Minimum 8px

### Text
- Minimum font size: 12px
- Line height: 1.4-1.6
- Paragraph width: Maximum 70 characters
